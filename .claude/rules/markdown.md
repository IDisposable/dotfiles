# Documentation

- Write in ASD-STE100 Simplified English.
- American spelling: favorite, behavior, color, catalog, centralize, organize, analyze,
  license. Watch the -our, -ise, -yse and -logue endings.
- State the fact and stop. Prefer a sentence or a table row to a paragraph.
- Do not restate what the code says.
- Do not write historical notes. Describe the current state only.
- No em-dashes, en-dashes, arrows or emoji.
- Domain vocabulary is permitted. Follow what is idiomatic to the repository.
